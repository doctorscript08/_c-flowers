## 🌼 C-Flowers
Este projecto é uma landing page simples, bonita e minimalista feita especificamente para um empreendimento de buquês de cetim no Lubango. Tem como objectivo dar uma nova cara ao negócio com um espaço online permitindo que ganhe mais visibilidade, profissionalismo e automatize o seu processo de vendas.

## 🔧 Tecnologias utilizadas
- HTML
- CSS
- JAVASCRIPT

## 📁 Estrutura do projecto
- `frontend`: arquivos HTML, CSS e JS
